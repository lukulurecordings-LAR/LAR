# Remote Courses Update

This package adds a production-ready remote-learning catalogue to the Lukulu Academy homepage.

## Included

- Six remote courses with modules, outcomes, duration, level and membership access.
- Responsive course cards with accessible expandable outlines.
- Main navigation link to `#remote-courses`.
- Course-specific, prefilled Academy enquiries.
- API validation for the `remote-course` service.
- Updated homepage section numbering.
- Integration guide at `docs/remote-courses.md`.

- Relative imports checked.
- Homepage, navigation and section anchor checked.
- Frontend/API enquiry service parity checked.
